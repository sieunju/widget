현재 브랜치의 변경사항을 분석하여 Feature PR을 작성해줘.

먼저 아래 명령어로 변경사항을 확인해:
1. 분기점 확인: `git merge-base HEAD origin/develop` (또는 적절한 부모 브랜치)
2. `git log <분기점>..HEAD --oneline` (현재 브랜치 커밋 목록)
3. `git diff <분기점>..HEAD --stat` (현재 브랜치 변경된 파일)
4. 필요시 주요 변경 파일 내용 확인

아래 템플릿 형식을 **정확히** 따라서 작성해:

```markdown
## 🤩 Feature

### 🔎 주요 변경 사항
- [ ] UI/UX 변경
- [ ] API 추가/변경
- [ ] DB Scheme 변경
- [ ] Permission 관련 변경
- [ ] 기타

### 🛠 구현한 기능
<!-- bullet point로 구현한 기능 나열 -->

### 🕹 테스트 결과
<!-- 테스트 방법이나 확인한 내용 -->

### 🤔 고민되는 사항
<!-- 구현 시 고민했던 부분. 없으면 "없음" -->

### 🐮 Etc.
<!-- 기타 공유할 내용. 없으면 비워둬 -->
```

작성 규칙:
1. 주요 변경 사항은 해당하는 항목에 `[x]` 체크
2. 구현한 기능은 명확하고 구체적으로 작성
3. 한국어로 작성
4. 마크다운 코드블록 없이 바로 출력
5. 작성 완료 후 `.claude/pr-text.md` 파일에 저장
