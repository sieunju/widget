현재 브랜치의 변경사항을 분석하여 Fix PR을 작성해줘.

먼저 아래 명령어로 변경사항을 확인해:
1. 분기점 확인: `git merge-base HEAD origin/develop` (또는 적절한 부모 브랜치)
2. `git log <분기점>..HEAD --oneline` (현재 브랜치 커밋 목록)
3. `git diff <분기점>..HEAD --stat` (현재 브랜치 변경된 파일)
4. 필요시 주요 변경 파일 내용 확인

아래 템플릿 형식을 **정확히** 따라서 작성해:

```markdown
## 🐛 Fix

### 🔎 버그 설명
<!-- 어떤 버그였는지 자세히 설명 -->

### 💥 재현 경로
<!-- 버그 재현 경로를 단계별로 -->
1.
2.
3.

### ✅ 수정 내용
<!-- 어떻게 수정했는지 설명 -->

### 🧪 테스트 결과
- [ ] 더이상 발생하지 않음
- [ ] 기존 기능에 영향 없음
- [ ] 관련 테스트 케이스 통과

### 🐔 Etc.
<!-- 기타 공유할 내용. 없으면 비워둬 -->
```

작성 규칙:
1. 버그 설명은 원인과 증상을 명확히 구분
2. 재현 경로는 번호로 단계별 작성
3. 수정 내용은 코드 레벨에서 어떻게 고쳤는지 설명
4. 테스트 결과는 확인된 항목에 `[x]` 체크
5. 한국어로 작성
6. 마크다운 코드블록 없이 바로 출력
7. 작성 완료 후 `.claude/pr-text.md` 파일에 저장
